Qué es y cómo se usa
Qué hace. Trámites te lleva a la web oficial de cada gestión y te cuenta qué necesitas antes de ir. No hace el trámite por ti.
Cómo se usa.
  1. Elige un atajo o busca el organismo o el trámite en el buscador.
  2. Toca el trámite para abrirlo. Verás para qué sirve, qué necesitas, los plazos y cómo se hace.
  3. Mira la etiqueta de cada ficha. Verificado quiere decir que se abrió la página oficial y se contrastó. Leído, no abierto quiere decir que se leyó un extracto. Pendiente de comprobar quiere decir que falta confirmar algún dato. Por verificar quiere decir que la fuente aún no se ha comprobado.
  4. Pulsa «Ir a la web oficial» y comprueba que el nombre de la web es el que indica la ficha.
  5. Si quieres preguntar a un ayuntamiento, algunas fichas te llevan a IDEAKEY para preparar el texto. Lo copias tú; nada se envía solo.

Qué significa cada etiqueta
  • ✔ Verificado: página oficial abierta y contenido contrastado, sin datos pendientes.
  • 👁 Leído, no abierto: el contenido sale de un extracto; no se ha abierto la página completa.
  • ◐ Pendiente de comprobar: falta confirmar algún dato concreto. Está marcado en su campo.
  • ⚠ Por verificar: la fuente o el enlace todavía no se han comprobado.
