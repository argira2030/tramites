Para todas las personas

🔍

Lo habitual

  • Leer una lista con anuncios delante.
  • Decidir cuál es la web oficial.
  • Abrir una, mirar el nombre y, si no es, volver atrás.
👀

Antes de abrir

IDEAKEY enseña el nombre de la web y si el enlace está ✔ verificado o ⚠ por verificar.

La persona comprueba el nombre ella misma y decide si pulsa «Ir a la web oficial».

🚫

Lo que IDEAKEY no hace

  • No sustituye a la web oficial: lleva hasta ella.
  • No pide ni escribe datos, ni hace el trámite.
  • Solo cubre los trámites de la lista.
  • Los enlaces se revisan a mano y pueden cambiar.
🧪

Lo que falta por saber

Es una maqueta. No se han medido toques, tiempo, errores ni fatiga. Lo que se dice de cada persona es una hipótesis por probar.

Falta probarla con personas.
